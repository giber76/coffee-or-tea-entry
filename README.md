One letter, coffee or tea: **A** — coffee.

The competition asks for exactly one letter, A for coffee or B for tea, and a judge compares letters two at a time on which choice feels more vivid, funnier or truer. Coffee wins that comparison on the brief's own order: more vivid first (dark, bitter, steaming — a fuller, more alive answer than tea's calm), funnier second (the "don't talk to me before coffee" wit), truer third (the honest default morning drink). One letter and nothing else — no word, no explanation, no punctuation.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
cat output/entry.txt
```

The program writes the single letter to `/output/entry.txt` (1 character, within the 1–1 gate).
